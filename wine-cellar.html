Connect to Supabase

Follow these steps to connect your wine cellar to a real database. Your data will then sync across any device.

  1. Go to supabase.com, create a free account and a new project.
  2. In your project, open the SQL Editor and run the setup query below to create your wines table.
  3. Go to Project Settings → API and copy your Project URL and anon public key.
  4. Paste them below and click Save.

SQL to run in Supabase SQL Editor:

create table wines (
  id uuid default gen_random_uuid() primary key,
  created_at timestamptz default now(),
  location text not null,
  shelf text,
  slot text,
  year integer,
  type text,
  grape text,
  winery text,
  name text,
  aging_candidate boolean default false,
  notes text
);
-- Allow public read/write (fine for personal use)
alter table wines enable row level security;
create policy "Allow all" on wines for all using (true) with check (true);
